# 🎓 CAMPUS SARTHI

> A C++-based Campus Management and Student Assistance System designed to provide students with useful campus-related information and management features.

---

## 📌 About the Project

**CAMPUS SARTHI** is a console-based C++ application developed to simplify campus-related tasks and provide students with an easy-to-use platform for accessing and managing information.

The project follows a modular structure with separate components for student management, administration, departments, campus guidance, and feedback.

---

## 🚀 Features

### 👨‍🎓 Student Management
- Add student records
- View student information
- Search student records
- Delete student records
- Store student data using text files

### 🔐 Admin Module
- Manage student records
- Add, view, and delete student information
- Perform administrative operations

### 🗺️ Campus Guide
- Provides campus-related guidance
- Helps students access important campus information

### 🏢 Department Module
- Provides information related to different departments
- Organizes department-related details

### 💬 Feedback System
- Allows users/students to provide feedback
- Stores feedback using text files

### 💾 File Handling
The project uses C++ file handling to store data persistently.

Data files include:
- `students.txt`
- `Feedback.txt`
